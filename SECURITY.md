# Security Policy

## Local Security Guarantee
Dependency Detective is a local-first application. Source code parsed during investigation remains strictly on the developer workstation.

## Exclusions
Default exclusions prevent indexing of sensitive configuration files (`.env`, `*.key`, `*.pem`, `credentials*`).

## Reporting Vulnerabilities
If you discover a security vulnerability in this project, please open a security advisory or email the maintainers directly.
